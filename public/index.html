Trust

Agent memory that knows where every memory came from. Two scripted agents work for two separate clients. Watch memories stay inside their matter, trace any memory to its sources and to the changes it influenced, and undo what a bad source taught.

The demo

1Two agents, two matters

Agent 1 works for Northwind, Agent 2 for Contoso. Each writes memories with their sources. Origin is attached by the server, not claimed by the agent.

2Try to cross the wall

Agent 2 asks for Northwind's memory. The request is checked on every call, refused, and logged in Contoso's audit trail without revealing anything about Northwind.

3Trace a memory

Why does Agent 1 believe "use shared money helpers"? Walk back to its sources, and forward to the session and pull request it influenced. Or click any node.

4Poison a source, then recover

A CI note claims billing tests are flaky. Agent 1 learns from it, builds on it, and merges a change. Remove the source and everything it taught is quarantined, with the affected change listed.

5Promote across the wall

A general technique from Northwind can help Contoso. It crosses only through review: client names and figures are stripped, a person approves, and Contoso sees it as advisory.

6Two sessions disagree

A third agent on Northwind concludes the opposite of an existing memory. Both are marked contested and still recalled, flagged, until a person decides. The decision becomes part of history.

7A source changes

round.ts moves past the version the agents learned from. Everything drawn from it is flagged stale, with the merged change to re-check. Re-verify against the new version to clear it.

8A new wall, mid-session

Agent 1's supervisor joins Contoso work. A wall goes up and Agent 1's live session is paused on its very next call.

Each visit gets its own throwaway scopes that delete themselves after an hour.
