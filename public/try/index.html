Try Trust in four steps

Two AI agents work on a client's contract. Watch one memory get saved, relied on, go stale when the contract changes, and get replaced, with its whole history kept. Each step is a real call to Trust.

  1. An agent reads a contract

    The intake agent reads Northwind's engagement letter, version 3, and saves what it learned. Trust tags the memory with where it came from.

  2. Another agent relies on it

    Later, the drafting agent asks how much notice Northwind needs. Trust answers from the tagged memory and records who relied on it.

  3. The contract changes

    Northwind signs version 4 of the letter. Trust hears that the source changed and marks every memory resting on it stale, before anyone acts on it again.

  4. The memory is replaced

    The intake agent reads version 4 and saves the new term. The old memory is marked replaced; its history stays.
